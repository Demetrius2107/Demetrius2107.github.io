# 此行山高路远

> 我口袋只剩玫瑰一片，此行又山高路远。——《小尖尖》

基于 **Hugo + FixIt 主题** 构建的个人博客，部署于 **GitHub Pages**，记录 Java、Python、Go 等技术学习与思考。

## 快速开始

```bash
# 本地预览
hugo server -D

# 构建静态站点
hugo --gc --minify

# 一键发布（构建并推送 GitHub Pages）
./publish.sh        # Windows 下用 publish.bat
```

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `content/posts/` | 博客文章（Markdown） |
| `content/about/` | 关于页面 |
| `static/admin/` | Sveltia CMS 后台配置 |
| `assets/` | 自定义样式与脚本 |
| `docs/` | 歌词等共享文档 |
